# AI Job Board

An AI-powered job board built with **Next.js, React, and TypeScript** that helps users discover job opportunities and generate job-related content using AI.

## Features

- Browse and search job listings
- AI-assisted job discovery
- AI-generated resume
- Dynamic job listing pages
- Responsive UI

## Tech Stack

Frontend
- Next.js
- React
- TypeScript
- Tailwind CSS
- shadcn/ui

APIs
- Inngest
- Clerk
- Uploadthing

Deployment
- Vercel
